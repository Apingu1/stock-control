CLIENT DEPLOYMENT

This folder is populated automatically after a successful server installation.

Run "01 - INSTALL SERVER.bat" first.

After installation this folder should contain the server-specific client files:

- ESC_CLIENT_SETUP_WINDOWS.bat
- Configure-Hosts.ps1
- client-config.ini
- stock-control-ca.crt

Copy the complete populated folder to each client computer and run ESC_CLIENT_SETUP_WINDOWS.bat as Administrator.

Do not use an old client deployment folder from a different server installation.
