# StkFlo

StkFlo is the on-premises materials, inventory and stock-control application.

The approved StkFlo interface, login layout and browser/PWA assets are maintained
on `feature/stkflo-rebrand`. Before deploying that branch, install and commit
the exact approved 3D artwork using
`scripts/install_stkflo_branding.sh` and the supplied branding ZIP.

See [StkFlo branding rollout](web/docs/stkflo-branding-rollout.md) for
instructions and acceptance checks.
